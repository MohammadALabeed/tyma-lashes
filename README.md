## English

### ✨ Project Overview

Tyma Lashes Studio is a polished, mobile-friendly salon website showcasing professional lash styling, extensions, and lifting services. It gives clients a convenient way to explore services, view customer reviews, and get in touch with the studio.

### 🚀 Features

- 📱 Responsive interface designed for mobile, tablet, and desktop.
- ⭐ Supabase-powered customer review submission and display.
- 🔐 Protected review-management dashboard using Supabase Auth and row-level security (RLS).
- 📝 Decap CMS for managing site content, services, and imagery.
- 🔎 SEO and social-sharing metadata, with Google Search Console verification configured to support discovery and indexing.

# صالون تيما لاشز - المنصة الرسمية

## ✨ نبذة عن المشروع

منصة رقمية أنيقة ومتجاوبة لصالون **Tyma Lashes**، تعرض خدمات الرموش واللفتنغ بطريقة واضحة وجذابة. تساعد العميلات على استكشاف الخدمات والأسعار، والاطلاع على تجارب العميلات، والتواصل مع الصالون بسهولة.

## 🌸 المميزات

- 📱 تصميم متجاوب يعمل على الهواتف والأجهزة اللوحية والحواسيب.
- ⭐ إرسال تقييمات العميلات وعرضها باستخدام قاعدة بيانات Supabase.
- 🔐 لوحة محمية لإدارة التقييمات، مع مصادقة Supabase وسياسات أمان على مستوى الصفوف (RLS).
- 📝 إدارة محتوى الموقع والخدمات والصور عبر Decap CMS.
- 🔎 بيانات وصفية لتحسين محركات البحث ومشاركة الروابط، مع إعداد التحقق من Google Search Console لدعم ظهور الموقع وفهرسته.

## 🧰 التقنيات المستخدمة

HTML5، CSS3، Tailwind CSS، JavaScript، Supabase (قاعدة البيانات والمصادقة)، Netlify، وDecap CMS.
